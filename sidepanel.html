저장됨

이제 아래 안내로 캘린더 앱에 가져오면 마이그레이션이 끝납니다.

Google Calendar

  1. PC 웹에서 Google 캘린더 설정 → 가져오기를 엽니다.
  2. “컴퓨터에서 파일 선택”으로 방금 받은 .ics 파일을 고릅니다.
  3. 가져올 캘린더를 고르고 “가져오기”를 누릅니다.

모바일 앱에서는 가져오기가 안 됩니다 — PC 웹에서 진행하세요.

Apple 캘린더

  1. Mac 캘린더 앱에서 파일 → 가져오기…를 엽니다.
  2. 받은 .ics 파일을 선택합니다.
  3. 추가할 캘린더를 고르고 “가져오기”를 누릅니다.

iPhone에서는 .ics 파일을 탭해 캘린더에 추가할 수 있습니다.

잘 들어갔는지 확인

  • 가져온 뒤 반복 일정 1건(예: 생일·기념일)을 열어 날짜·시간이 맞는지 확인하세요.
  • 같은 일정이 두 번 보이면, 가져온 캘린더를 통째로 지우고 한 번만 다시 가져오면 됩니다.
  • 시간이 어긋나면 캘린더 앱의 표시 시간대가 한국 시간인지 확인하세요.

공유 캘린더 경고

이 도구는 공식 TimeTree export 기능이 아닙니다. 현재 로그인된 browser session에서 사용자가 접근 가능한 calendar data를 local file로 저장합니다.

Shared calendar에는 다른 참가자의 이름, 일정, memo, comment, image 등 personal information이 포함될 수 있습니다.

Export file은 사용자의 책임으로 보관해야 하며, 외부로 전송하지 않습니다. 다른 참가자의 정보를 내보내는 경우, 그 동의를 확인할 책임은 사용자에게 있습니다.
