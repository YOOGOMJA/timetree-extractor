# TimeTree Exporter 개인정보 처리방침 (초안)

> 상태: **초안(2026-06-13)**. Chrome Web Store 제출(#94)에 필요한 공개 문서. 게시 전 법률 검토 필요(아래 "법률 검토 필요 항목"). 근거: `docs/specs/privacy-and-local-only-boundary.md`, ADR 0006.

**최종 수정일**: 2026-06-13

## 요약 (plain language)

TimeTree Exporter는 **로컬 전용** Chrome 확장 프로그램입니다. 로그인된 TimeTree 웹 화면에서 사용자가 접근 가능한 캘린더 일정을 **사용자의 기기 안에서** ICS/JSON 파일로 변환해 저장합니다.

- **서버가 없습니다.** 개발자는 어떤 서버도 운영하지 않으며, 사용자의 데이터를 **수집·전송·열람할 수 없습니다.**
- 일정 데이터는 **사용자 기기를 떠나지 않습니다.** 외부로 전송되지 않습니다.
- 로그인 정보(비밀번호·쿠키·세션 토큰·CSRF 헤더 등)는 **저장하지 않습니다.**
- 광고·분석(analytics)·트래킹이 **없습니다.**

## 1. 수집·처리하는 정보

### 1-1. 일정 데이터 (기기 내 처리, 저장 안 함)
확장은 내보내기를 수행하는 동안에만, 사용자가 **선택한 캘린더**의 일정(제목·시간·반복 규칙·메모·라벨 등)을 브라우저 메모리에서 정규화합니다. 이 데이터는:
- 사용자가 직접 저장하는 **내보내기 파일(ICS/JSON)에만** 담깁니다.
- 확장이 별도로 보관하거나 외부로 보내지 않습니다.
- **데이터 최소화**: 참가자·첨부의 *내용*(이름·이미지·파일)은 포함하지 않고 **개수만** 표기합니다. 첨부 바이너리는 내보내지 않습니다.

### 1-2. 로컬 메타데이터 (기기 내 `chrome.storage`)
내보내기 기록 용도로 **메타데이터만** 사용자 기기에 저장합니다. 일정 내용·캘린더 이름·개인정보는 저장하지 않습니다. 저장 항목:
- 내보낸 시각, 캘린더 **개수**(이름 아님), 기간(전체/날짜), 포맷(ICS/JSON), 내보낸 일정 **건수**, 경고 **건수**, 생성된 파일명.

이 메타데이터는 사용자 기기에만 있으며, 확장 삭제 또는 브라우저 데이터 삭제로 제거됩니다.

### 1-3. 수집하지 않는 것
- 로그인 자격증명, 쿠키, 세션/CSRF 토큰 — **저장·전송 안 함.**
- 위치, 결제 정보, 기기 식별자, 사용 행태(analytics) — **수집 안 함.**

## 2. 권한과 사용 목적

- **host 권한 `https://timetreeapp.com/*`**: 사용자가 로그인한 TimeTree 화면에서 일정을 읽어 내보내기 위해서만 사용합니다. 다른 사이트에 접근하지 않습니다.
- 읽기는 **사용자가 패널을 열고 명시적으로 실행할 때만** 일어납니다. 백그라운드 폴링·자동 동기화가 없습니다.

## 3. 제3자 제공·공유

**없습니다.** 데이터가 기기를 떠나지 않으므로 제3자(분석·광고·호스팅 포함)와 공유하지 않습니다. 단, 사용자가 만든 내보내기 파일을 **사용자 본인이** Google Calendar·Apple Calendar 등에 가져오는 것은 사용자의 행위이며, 그 시점부터는 해당 서비스의 처리방침이 적용됩니다.

## 4. 공유 캘린더의 타인 정보

공유(가족·그룹) 캘린더에는 **다른 참가자의 개인정보**(이름·일정·메모 등)가 포함될 수 있습니다. 확장은 내보내기 전에 이 사실을 경고하고 사용자 동의를 받습니다. 내보낸 파일의 보관·취급 책임은 사용자에게 있습니다. (참가자·첨부의 내용은 기본적으로 포함하지 않고 개수만 표기합니다.)

## 5. 보관·삭제

- 일정 데이터: 확장이 보관하지 않음(파일은 사용자가 관리).
- 로컬 메타데이터: 사용자가 확장을 삭제하거나 브라우저 저장소를 비우면 삭제됩니다.

## 6. 이용자 권리

데이터가 사용자 기기에만 있으므로, 사용자는 파일·로컬 저장소 삭제로 **직접 모든 데이터를 통제·삭제**할 수 있습니다. 개발자는 사용자 데이터를 보유하지 않으므로 별도 열람/삭제 요청 대상 데이터가 없습니다.

## 7. 아동 개인정보

본 확장은 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

## 8. 보안

데이터가 기기를 떠나지 않고 자격증명을 저장하지 않음으로써 전송·유출 위험을 구조적으로 줄입니다. 확장 코드는 원격 코드 실행 없이 패키지에 포함된 스크립트만 사용합니다.

## 9. 처리방침 변경

데이터 처리 방식이 바뀌면 본 방침을 갱신하고 최종 수정일을 변경합니다.

| 규정 | 상태 | 비고 |
| --- | --- | --- |
| Chrome Web Store 사용자 데이터 정책 | 검토 필요 | 단일 목적·최소 권한·원격 코드 금지·공개 처리방침 URL 충족 방향. 제출 폼의 data usage 선언과 일치시켜야 함(#94). |

| GDPR (EU 사용자) | 법률 검토 필요 | 개발자가 데이터를 받지 않으면 controller 의무가 최소화되나, 스토어 글로벌 배포 시 확인 필요. |
| CCPA (캘리포니아) | 법률 검토 필요 | "판매/공유 없음" 진술의 적합성 확인. |

## 법률 검토 필요 항목

| 항목 | 이유 | 우선순위 |
| --- | --- | --- |
| 데이터 미보유 구조의 법적 의미 | "개발자가 데이터를 받지 않음"이 PIPA/GDPR controller 의무 면제로 이어지는지 | 높음 |
| TimeTree 데이터 재사용·AUP/저작권 | 타 서비스 데이터를 사용자가 추출하는 행위의 약관/법적 적합성(#93와 연동) | 높음 |
| 공유 캘린더 타인 정보 취급 고지의 충분성 | 제3자 개인정보가 파일에 포함될 수 있음 — 고지·동의 수준 | 높음 |
| 글로벌 배포 시 관할별 의무 | 스토어는 전세계 노출 → GDPR/CCPA 적용 가능성 | 중간 |
