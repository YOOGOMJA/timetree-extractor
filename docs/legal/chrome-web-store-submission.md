## 권한 사유 (제출 폼 "권한 정당화"에 사용)

| 권한 | 사유 (사용자 관점) |
| --- | --- |
| `host_permissions: https://timetreeapp.com/*` | 로그인된 TimeTree 화면에서 사용자의 캘린더 일정을 읽어 내보내기 위해. 다른 사이트엔 접근하지 않음. |
| `sidePanel` | 확장 UI(수집 대시보드·내보내기)를 사이드 패널로 표시하기 위해. |
| `storage` | 내보내기 **기록 메타데이터**(시각·건수·포맷 등)만 사용자 기기에 저장. 일정 내용·개인정보는 저장하지 않음. |
| `tabs` | 활성 탭이 TimeTree인지 감지해 패널을 적절히 안내하고, "TimeTree 열기"로 해당 탭을 열거나 포커스하기 위해. 탭 내용을 수집하지 않음. |

> 검토 메모: `tabs`는 비교적 넓은 권한이다. 심사에서 지적되면, 활성 탭 URL 확인이 host_permissions로 충분한 범위인지 재검토해 축소를 시도한다(현재는 탭 전환 감지·탭 열기 관리에 사용).

## 데이터 사용 선언 (제출 폼 "데이터 사용" — privacy policy와 일치 필수)

- 수집하는 사용자 데이터: **개발자가 수집하는 데이터 없음**(서버 없음, 전송 없음). 일정 데이터는 사용자 기기 안에서만 처리되어 사용자가 저장하는 파일로만 나감.
- 판매/제3자 공유: **없음**.
- 용도: 사용자가 선택한 캘린더의 일정을 로컬에서 내보내기 파일로 변환(단일 목적).
- 인증 정보: 수집/저장하지 않음.

## 리스팅 카피 (초안)

- **요약(짧은 설명, ~132자)**: 로그인된 TimeTree 웹의 개인·공유 캘린더 일정을 내 기기에서 ICS/JSON으로 내보냅니다. 서버 없음, 전송 없음, 로컬 전용.
- **카테고리**: 생산성(Productivity)
- **상세 설명(초안)**:
  > TimeTree에는 공식 내보내기가 없습니다. TimeTree Exporter는 로그인된 TimeTree 웹 화면에서 사용자가 접근 가능한 캘린더 일정을 **사용자 기기 안에서** 표준 ICS 또는 JSON 파일로 변환합니다.
  >
  > - 개인·공유(가족/그룹) 캘린더 모두 내보내기

  > - **로컬 전용**: 서버가 없고, 어떤 데이터도 외부로 전송하지 않습니다. 로그인 정보를 저장하지 않습니다.

  >
  > 공유 캘린더에는 다른 참가자의 정보가 포함될 수 있어, 내보내기 전 경고와 동의를 표시합니다.
