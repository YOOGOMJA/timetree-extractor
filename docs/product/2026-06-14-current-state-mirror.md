## 1. 핵심 포인트와 핵심 가치

**한 줄**: TimeTree에 없는 "내보내기"를, 내 기기 안에서, 손실 없이.

| 핵심 포인트 | 내용 | 근거 |
| --- | --- | --- |
| 잡(Job) | 공식 export가 없는 TimeTree의 **개인+공유 일정을 Google/Apple로 마이그레이션** | value-proposition.md |
| 차별점 1 — 로컬 전용 | 서버 없음·전송 0·credential 미저장. 온라인 변환기의 "남 서버에 붙여넣기" 리스크 제거 | privacy-policy.md |
| 차별점 2 — 충실도 | 반복·시간대·RECURRENCE-ID 보존, Google import 실검증(#85). **no-silent-loss**(제외 건수 투명) | recurrence runbook |
| 차별점 3 — 공유 데이터 1급 | 가족/그룹 캘린더도 내보냄(막지 않음). 단 타인정보 최소화(내용 미포함·개수만)+동의 | #75·#81 |
| 신뢰 장치 | 수집 데이터 대시보드(캘린더·카테고리·이슈 드릴다운)로 "무엇이 담겼는지" 먼저 보여줌 | state-results |

**핵심 가치 명제**: 떠나거나 합치려는 사용자에게, 로그인된 내 TimeTree의 개인·공유 일정을 손실 없이 표준 캘린더 파일로 꺼내주는 **로컬 전용 확장**.

## 3. 유저 시나리오

**페르소나**: TimeTree를 수년 쓴 개인/가족 대표. Google·Apple로 이전·통합하려 함. 약간의 기술 자신감(확장 설치, 파일 import).

### S1. 마이그레이터 (1차 잡, 해피패스)
1. TimeTree 웹 로그인 상태에서 확장 패널을 연다.
2. "캘린더 수집" → 개인·공유 캘린더 목록을 본다.
3. 캘린더 선택(기본 전체)·기간(기본 전체) 후 "분석".
4. 대시보드에서 캘린더별·카테고리·이슈·총 건수를 검토(신뢰 확인).
5. 포맷(ICS) 선택 → "내보내기" → 공유 경고 동의 → 파일 저장.
6. 가이드대로 Google/Apple에 가져오기 → 마이그레이션 종료.

### S2. 아카이버 (백업)
- S1과 동일하되 포맷 JSON 선택, 가이드 없이 대시보드에 머물러 로컬 사본 확보.

### S3. 비-TimeTree 진입
- TimeTree가 아닌 탭에서 패널을 열면 "TimeTree 열기" 안내 → 클릭 시 탭 이동·자동 연결.

### S4. 실패/엣지
- API 변경/네트워크 실패 → "형식이 바뀐 듯/접근 실패" 안내 + "다시 시도".
- 일부 일정 제외(미지원 반복·기간 밖) → 대시보드 "발견된 이슈"에서 사유 드릴다운.

## 4. 현재 화면 목록 (실측 8 + 모달 1)

| # | state id | 역할 | 진입 |
| --- | --- | --- | --- |
| A | `panel-not-timetree` | 비-TimeTree 안내 + "TimeTree 열기" | 활성탭이 TimeTree 아님 |
| B | `state-idle` | 진입(히어로 "캘린더 수집") + 최근 내보내기 | TimeTree·초기 |
| C | `state-loading` | 스피너 | 수집/분석 중 |
| D | `state-setup` | 캘린더 선택 + 기간(전체기간 토글 #84) | 수집 완료 |
| E | `state-results` | **대시보드**: 수집요약·캘린더·카테고리·이슈·전체보기·내보내기 | 분석 완료 |
| F | `state-detail` | 전체 일정 가상화 목록 + 검색 | "전체 일정 보기" |
| G | `state-guide` | 내보내기 완료 + Google/Apple 가져오기 가이드 | ICS 내보내기 후 |
| H | `state-error` | 오류 메시지 + "다시 시도" | 실패 |
| M | `warning-modal` | 공유 캘린더 경고 + 동의 체크 | 내보내기 직전 |

## 5. 스토리보드 (시나리오 × 화면 흐름)

```
S1 마이그레이터:
  [A?]→ B(idle) ──수집──▶ C(loading) ──▶ D(setup)
                                            │ 분석
                                            ▼
                                          C(loading) ──▶ E(results/대시보드)
                                                            │ 내보내기
                                                            ▼
                                                          M(공유 경고·동의)
                                                            │ 확정(ICS)
                                                            ▼
                                                          G(완료+가이드) ──▶ (Google/Apple import)
  E ──"전체 일정 보기"──▶ F(detail) ──←──▶ E
  G ──"대시보드로"──▶ E   /   "처음으로"──▶ B

S2 아카이버: …E에서 JSON 내보내기 → M → 파일 저장(가이드 G 없이 E 유지)

S3 비-TimeTree: A ──"TimeTree 열기"──▶ (탭 이동) ──자동연결──▶ B

S4 실패: (C 중 실패) ──▶ H(error) ──"다시 시도"──▶ B
        (E) 이슈는 "발견된 이슈" 드릴다운으로 사유 확인
```
